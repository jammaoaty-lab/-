# UI 设计文档

## 设计理念

- **视觉语言**: 未来科技感 + 霓虹渐变
- **设计风格**: 极简卡片式布局
- **交互体验**: 流畅的微动画 + 清晰的反馈
- **响应式设计**: 完美适配 PC 和移动设备

## 1. 设计系统

### 1.1 色彩规范

#### 主色调
| 颜色 | Hex | 用途 |
|------|-----|------|
| 紫色-500 | `#a855f7` | 主按钮、渐变、高亮 |
| 紫色-600 | `#9333ea` | 悬停状态 |
| 粉色-500 | `#ec4899` | 渐变辅助色 |
| 蓝色-500 | `#0ea5e9` | 次要操作、链接 |

#### 中性色
| 颜色 | Hex | 用途 |
|------|-----|------|
| Slate-950 | `#020617` | 背景色 |
| Slate-900 | `#0f172a` | 卡片背景 |
| Slate-800 | `#1e293b` | 次级背景 |
| Slate-700 | `#334155` | 边框、分割线 |
| Slate-500 | `#64748b` | 次级文字 |
| Slate-400 | `#94a3b8` | 辅助文字 |
| Slate-200 | `#e2e8f0` | 主要文字 |

#### 功能色
| 颜色 | Hex | 用途 |
|------|-----|------|
| 绿色-500 | `#10b981` | 成功、正常状态 |
| 黄色-500 | `#eab308` | 警告、注意 |
| 红色-500 | `#ef4444` | 错误、危险 |

### 1.2 渐变规范

```css
/* 主渐变 */
gradient-purple-pink: linear-gradient(135deg, #a855f7, #ec4899)
gradient-blue-cyan: linear-gradient(135deg, #0ea5e9, #06b6d4)
```

### 1.3 字体规范

#### 字体家族
- 中文字体: Inter, PingFang SC, Microsoft YaHei
- 英文字体: Inter, SF Pro Display

#### 字号体系
| 字号 | 应用场景 |
|------|---------|
| 48px/3rem | 特大标题 |
| 32px/2rem | 页面标题 |
| 24px/1.5rem | 卡片标题 |
| 18px/1.125rem | 正文强调 |
| 16px/1rem | 正文 |
| 14px/0.875rem | 辅助文字 |

- 700: 标题、强调

- 400: 正文、辅助

## 2. 组件设计规范

### 2.1 按钮 (Button)

#### 变体
```
Primary: 渐变背景 + 圆角 + 阴影
Secondary: 边框 + 悬停变色
Ghost: 透明 + 悬停背景
```

#### 尺寸
```
Large: 高度 48px, 内边距 24px, 字号 16px
Medium: 高度 40px, 内边距 16px, 字号 14px
Small: 高度 32px, 内边距 12px, 字号 12px
```

#### 交互状态
```
默认: 正常样式
Hover: 上浮 2px + 阴影增强
Active: 按下效果 + 透明度
Disabled: 半透明 + 不可点击
```

### 2.2 卡片 (Card)

#### 基础样式
```
背景: slate-900
边框: slate-800
圆角: 12px
阴影: 基础阴影
```

#### 悬浮效果
```
悬停: 边框变色 (purple-500/30) + 阴影增强
```

### 2.3 输入框 (Input)

#### 样式规范
```
背景: slate-800
边框: slate-700
圆角: 8px
聚焦: 边框变 purple-500 + 发光
```

### 2.4 标签 (Tag)

#### 尺寸与变体
```
尺寸: 24px/14px 或 20px/12px
变体: 彩色背景、边框、实心
```

├─────────────────────────────────────────┤
│      作品展示区 (6列网格)                │
├─────────────────────────────────────────┤
│      模板精选区                         │
├─────────────────────────────────────────┤

#### 作品展示区设计
- **响应式网格**: xl:6列, lg:5列, md:4列, sm:3列

- **作品卡片**:

## 4. 交互与动画

### 4.1 动画时间曲线
```css
cubic-bezier(0.4, 0, 0.2, 1) /* 缓入缓出 */
cubic-bezier(0.34, 1.56, 0.64, 1) /* 弹性动画 */
```

### 4.2 过渡动画
| 时长 | 场景 |
|------|------|
| 150ms | 悬停反馈 |
| 250ms | 页面切换 |
| 300ms | 模态框展示 |
| 500ms | 数据加载 |

### 4.3 微交互
```
按钮按下: 缩小 95%
卡片悬停: 上浮 4px + 阴影
输入聚焦: 轻微发光 + 边框变色
```
