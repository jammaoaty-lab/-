# 8. 硬件配置与分步部署方案

## 8.1 硬件/云资源分档配置

### 档位1：入门版（个人/小团队 初期上线）

| 组件 | 配置 | 数量 | 用途 |
|------|------|------|------|
| Web服务器 | 2核4G，4M带宽 | ×1 | 部署Web服务、数据库、队列 |
| 本地推理 | RTX3090/4060Ti (16~24G显存) | ×1 | 本地视频合成 |
| 云端推理 | 弹性GPU实例 | 按需 | 高画质视频生成 |
| 云端训练 | 公有云PAI/TI 24G弹性GPU | 按量计费 | LoRA/模型训练 |
| OSS存储 | 5TB | - | 文件、模型、作品存放到 |
| 附加服务 | Redis、TP6队列、监控 | - | 后台服务支持 |

### 档位2：进阶版（稳定流量、社区活跃、长视频产出量大）

| 组件 | 配置 | 数量 | 用途 |
|------|------|------|------|
| Web服务器 | 2核4G | ×2 | 负载均衡 |
| 本地推理 | RTX4090 24G | ×1 | 本地视频合成 |
| 云端推理 | A10 24G GPU | ×1（包月固定）| 稳定生产 |
| 云端训练 | 公有云包月24G GPU | - | 训练服务 |
| OSS存储 | 10TB | - | 文件存储 |
| 附加服务 | 独立FFmpeg服务器、队列集群、监控告警 | - | 高可用架构 |

### 档位3：旗舰版（商业运营、高并发、大量长视频生产）

| 组件 | 配置 | 数量 | 用途 |
|------|------|------|------|
| Web服务器 | 4核8G + 负载均衡 | ×2 | 负载均衡 |
| 本地推理 | RTX4090 | ×2 | 本地视频合成集群 |
| 云端推理 | A10 24G | ×3~4（K8s集群）| 高并发推理 |
| 云端训练 | A100 40G | ×2 | 大规模训练 |
| OSS存储 | 20TB+ | - | 文件存储 |
| 附加服务 | 云端媒体服务、监控告警、数据备份集群 | - | 完整商业架构 |

## 8.2 分步部署流程

### 步骤1：环境准备
```bash
# 更新系统
yum update -y
# 安装必要工具
yum install -y git wget vim nginx mysql redis
# 安装 Docker 和 Docker Compose
```

### 步骤2：后端部署
```bash
cd /data/wwwroot/ai_drama_platform
# 上传代码
# 配置 .env 文件
cd web_main
composer install
# 数据库迁移
php think migrate:run
# 权限初始化
```

### 步骤3：前端部署
```bash
cd frontend
npm install
npm run build
# Nginx 配置
```

### 步骤4：本地推理部署
```bash
cd ai_local_infer
chmod +x scripts/*.sh
./scripts/start.sh
```

### 步骤5：定时任务配置
```bash
# 设置执行权限
chmod +x scripts/*.sh
# 使用 crontab -e 编辑定时任务
# 复制 scripts/crontab.conf 的内容
```

### 步骤6：后台初始配置
1. 创建初始超级管理员账号
2. 配置菜单和角色权限
3. 配置第三方服务API密钥
4. 设置监控告警
