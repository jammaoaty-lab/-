# 山野户外 - 安装包

## 版本信息

- 版本号：1.0.0 (build 1)
- 构建类型：release（生产）
- 平台：Android

## 安装包选择

| 文件 | 架构 | 体积 | 适用设备 |
|------|------|------|---------|
| 山野户外-arm64-v8a.apk | 64 位 ARM | 17.6MB | 近 3 年主流安卓手机（推荐） |
| 山野户外-armeabi-v7a.apk | 32 位 ARM | 15.0MB | 较老的安卓手机 |
| 山野户外-x86_64.apk | 64 位 x86 | 19.0MB | Android 模拟器 |

## 安装方法

1. 下载对应你手机的 APK 文件
2. 手机端允许「安装未知来源应用」
3. 点击 APK 文件进行安装

## 说明

- 按 ABI 拆分以减小体积，请勿使用 143MB 的 debug 包
- 当前版本使用 debug 签名，正式上架前需替换为正式签名
- release 包已开启 R8 混淆（默认配置）
