# AI 漫剧短剧创作平台

一个完整的AI驱动的漫剧、短剧、动漫创作平台，支持从剧本生成到最终视频合成的全流程创作。

## 项目架构

### 技术栈

- **前端**: React 18 + TypeScript + Vite + TailwindCSS
- **后端**: PHP 8.1 + ThinkPHP 6.0
- **数据库**: MySQL 8.0 + Redis
- **消息队列**: RabbitMQ
- **AI能力**: 
  - 本地推理: Python + ComfyUI
  - 云端推理: Docker + K8s
  - 视频生成: 火山引擎/可灵/Minimax
  - 语音合成: 火山引擎语音/阿里云智能语音

## 核心功能

### 前台功能
- **首页**: 6列作品展示、热门推荐、模板专区
- **创作工作台**: 
  - AI编剧工具
  - 角色捏脸系统
  - 无限画布分镜
  - 可视化工作流
  - 导演运镜控制台
- **长视频生成**: 剧本自动分镜 → 批量生成镜头 → FFmpeg合成
- **模型训练**: 支持用户上传图片训练专属画风模型
- **社区互动**: 作品广场、话题圈子、用户榜单
- **个人中心**: 用户信息、Token管理、会员体系

### 后台管理系统
- **系统总览**: 数据大屏、统计报表、实时监控
- **权限管理**: RBAC权限体系、管理员管理、角色配置
- **用户管理**: 全量用户、等级标签、会员管理、Token账务
- **内容管理**: 作品审核、推荐配置、分类管理
- **社区运营**: 圈子话题、帖子审核、打赏管理
- **任务管理**: 创作任务、长视频任务、队列监控
- **AI模型管理**: 训练任务、公共模型、私有模型审核
- **算力账务**: Token流水、订单管理、分成结算
- **风控安全**: 内容审核、违规记录、账号处罚
- **系统运维**: 队列管理、服务器监控、文件管理、定时任务

## 快速开始

### 前端开发

```bash
cd frontend
npm install
npm run dev
```

访问 http://localhost:3000

### 后台管理

访问 http://localhost:3000/admin

### 默认账号

- 前台用户: 需注册
- 后台管理员: admin / admin123 (生产环境请修改)

## 开发规范

### 前端规范
- 使用 TailwindCSS 进行样式开发
- 组件遵循单一职责原则
- 使用 Zustand 进行状态管理
- API 请求统一封装

### 后端规范
- 遵循 ThinkPHP 6.0 规范
- API 接口遵循 RESTful 风格
- 使用环境变量管理敏感配置
- 队列任务异步处理耗时操作
